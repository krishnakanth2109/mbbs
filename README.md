Study MBBS Abroad - Landing Page
This repository contains the source code for a responsive landing page designed to help prospective students explore MBBS opportunities abroad. The site features country listings, program details, and a lead generation form.

🌍 Live Demo
View the Live Demo Here https://sunny-toffee-fecc08.netlify.app/

🛠 Technologies Used
HTML5: Semantic markup for structured content.
CSS3 & Tailwind CSS: For responsive and modern styling.
JavaScript: Form validation and interactivity.
Google Analytics & Facebook Pixel: Integrated for performance tracking.
✨ Features
Responsive Design: Fully responsive across all devices using Tailwind CSS.
Country Listings: Detailed pages for Russia, Uzbekistan, Kazakhstan, Philippines, Georgia, Kyrgyzstan, and Egypt.
Lead Generation Form: Collects user information with built-in form validation.
SEO Optimization: Meta tags and optimized content for better search visibility.
Performance Tracking: Google Analytics and Facebook Pixel integrated.
